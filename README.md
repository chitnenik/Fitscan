# FitScan prototype

Mobile-first Next.js app that scans a body (simulated LiDAR), verifies clothing sizes against brand size charts, and aggregates retailer catalogs filtered to what fits.

```bash
npm install
npm run dev      # http://localhost:3000 (open in a phone-sized viewport)
npm run build
```

## Screens
- `/` Home: active body profile, profile switcher, items verified in your size
- `/scan` Feature A: simulated depth scan (point cloud, depth grid, progress ring, optional live camera), extracted measurements, Three.js avatar with fit heat map
- `/catalog` Features B + D: search with category parsing ("Men's Jackets", "Summer Dresses"), filters (retailer, type, color, price), **Matches My Size** toggle, affiliate-style buy links pre-filled with the recommended size
- `/check` Feature C: paste a product link, mock scraper resolves brand + size chart, outputs VERIFIED FIT / FIT WARNING, avatar showing pinch/gap zones, alternative sizes and similar items in your size
- `/fit` Fit preview for any catalog item and size

## Mock data (`src/data`)
- `userScans.json` sample body profiles (new scans persist in localStorage)
- `catalog.json` 40 products across Amazon, Zara, ASOS, Nike with per-size stock
- `sizeCharts.json` per-brand men's/women's size matrices (cm)

`catalog.json` and `sizeCharts.json` are generated by `node scripts/generate-data.mjs`.

## Fit engine (`src/lib/fit.ts`)
Each size maps to body-measurement ranges. A zone is **tight** if the measurement exceeds the max by >0.5cm, **loose** if it falls >2-3cm under the min, otherwise **perfect**. A size fits when every zone relevant to the garment type is perfect.
